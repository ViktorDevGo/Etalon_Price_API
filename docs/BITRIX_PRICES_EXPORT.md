# Выгрузка цен и остатков для каталога шин

## Описание

Скрипт `cmd/export-bitrix-prices/main.go` создает CSV файл для **обновления цен и остатков** товаров в 1C-Битрикс.

**Назначение:** Обновление информации о ценах и наличии товаров без изменения самого каталога.

## Отличие от полной выгрузки

| Характеристика | Полная выгрузка (export-bitrix-updated) | Цены и остатки (export-bitrix-prices) |
|---------------|----------------------------------------|--------------------------------------|
| **Файл** | Каталог_шины_YYYYMMDD.csv | Переоценка_шины_YYYYMMDD.csv |
| **Колонок** | 74 колонки | 5 колонок |
| **Данные** | Полная информация о товаре | Только цены и остатки |
| **Товаров** | ~53,690 (все из nomenclature) | ~5,783 (только с остатком > 4) |
| **Источник** | nomenclature_tyres + tyres_prices_stock | tyres_prices_stock |
| **Использование** | Первоначальная загрузка каталога | Регулярное обновление цен/остатков |

## Формат файла

CSV файл содержит 5 колонок:

| Колонка | Источник | Описание |
|---------|----------|----------|
| **IE_XML_ID** | tyres_prices_stock.cae | Артикул товара |
| **IP_PROP171** | provider | "1 день" для особых поставщиков, иначе пусто |
| **QUANTITY** | SUM(stock) | Суммарный остаток по CAE |
| **CV_PRICE_1** | MIN(price) × 1.12 | Минимальная цена + наценка 12% |
| **CV_CURRENCY_1** | константа "RUB" | Валюта |

## Бизнес-логика

### 1. Источник данных
- **Таблица:** `tyres_prices_stock`
- Группировка по `cae` (артикул)
- Агрегация цен и остатков по всем складам

### 2. Фильтр по остатку
- **Условие:** `SUM(stock) > 4`
- Экспортируются только товары с достаточным остатком
- Товары с остатком 1-4 шт **не включаются** в выгрузку

### 3. QUANTITY (остаток)
```sql
SUM(p.stock) as total_stock
HAVING SUM(p.stock) > 4
```
- Суммируется остаток по всем складам
- Только если больше 4 штук

### 4. CV_PRICE_1 (цена)
```sql
MIN(p.price) * 1.12
```
- Минимальная цена среди всех складов
- Добавляется наценка 12%
- Цены в БД уже в рублях (не копейках!)

### 5. IP_PROP171 (особый поставщик)
```sql
MAX(CASE WHEN p.provider IN ('Группа Бринекс', 'Северавто') THEN 1 ELSE 0 END)
```
- Если товар есть у особого поставщика → "1 день"
- Иначе → пустое значение

## SQL Запрос

```sql
SELECT
    p.cae,
    MAX(CASE WHEN p.provider IN ('Группа Бринекс', 'Северавто') THEN 1 ELSE 0 END) as has_special_provider,
    SUM(p.stock) as total_stock,
    MIN(p.price) as min_price
FROM tyres_prices_stock p
GROUP BY p.cae
HAVING SUM(p.stock) > 4
ORDER BY p.cae
```

## Когда использовать

### Используйте этот скрипт когда:
- ✅ Нужно обновить цены и остатки существующих товаров
- ✅ Каталог уже загружен в Битрикс
- ✅ Товары не изменились, изменились только цены/остатки
- ✅ Требуется быстрое обновление (маленький файл, 5 колонок)

### Используйте полную выгрузку когда:
- ✅ Первоначальная загрузка каталога
- ✅ Добавились новые товары
- ✅ Изменились характеристики товаров (размеры, модели и т.д.)
- ✅ Нужен полный каталог (53,690 товаров)

## Важные замечания

### ⚠️ Формат цен в БД
- Цены в таблице `tyres_prices_stock` хранятся в **рублях**, а НЕ в копейках
- Значение `38219` в колонке `price` = 38,219₽

### ⚠️ Фильтр остатков
- Экспортируются **ТОЛЬКО** товары с остатком > 4
- Товары с остатком 1-4 шт не включаются в файл
- Это отличается от полной выгрузки, где все товары экспортируются

### ✅ Преимущества
- Маленький размер файла (~144 KB против 11 MB)
- Быстрый импорт (5,783 позиции против 53,690)
- Только актуальные данные (товары в наличии)
- Можно запускать часто (ежедневно, ежечасно)
