# Выгрузка каталога шин

## Описание

Скрипт `cmd/export-bitrix-updated/main.go` создает CSV файл с каталогом **легковых шин** (tiretype = "Легковая") для импорта в 1C-Битрикс.

## Формат имени файла

Файл создается автоматически с текущей датой:
- `Каталог_шины_YYYYMMDD.csv` - легковые шины

Пример: `Каталог_шины_20260316.csv`

## Формат CSV

CSV файл содержит 74 колонки в формате, совместимом с 1C-Битрикс.

## Бизнес-логика

### 1. CP_QUANTITY (остаток)
- **Источник:** таблица `tyres_prices_stock`, колонка `stock`
- **Расчет:** `SUM(stock)` по всем складам для одного `cae`
- **Логика отображения:**
  - Если `SUM(stock) <= 4` → **CP_QUANTITY = 0** (товар в каталоге, но недоступен для заказа)
  - Если `SUM(stock) >= 5` → **CP_QUANTITY = реальный остаток**
- **Экспорт:** все товары включаются в выгрузку, независимо от остатка

### 2. CV_PRICE_1 (цена продажи)
- **Источник:** таблица `tyres_prices_stock`, колонка `price`
- **Расчет:** `MIN(price) × 1.12`
  - Берем минимальную цену среди всех складов для одного `cae`
  - Добавляем наценку 12%
- **Формат цены:**
  - ✅ Цены в БД хранятся в **рублях** (не копейках!)
  - Пример: `9546` в БД = 9,546₽ → `9546 × 1.12 = 10,691.52₽`

### 3. IP_PROP171 (особый поставщик)
- **Источник:** таблица `tyres_prices_stock`, колонка `provider`
- **Расчет:** проверка наличия товара у особых поставщиков
  - Если хотя бы на одном складе `provider IN ('Группа Бринекс', 'Северавто')` → ставим **"1 день"**
  - Иначе → пустое значение
- **SQL логика:**
  ```sql
  MAX(CASE WHEN p.provider IN ('Группа Бринекс', 'Северавто') THEN 1 ELSE 0 END)
  ```
- **Значение:** текст "1 день" (срок доставки)

### 4. Фильтр по tiretype
- Экспортируются **только легковые шины**: `WHERE tiretype = 'Легковая'`
- Мотошины (tiretype = "Мотошина") **не экспортируются**

### 5. Группировка
- Группировка по `cae` (артикул товара)
- Один `cae` = одна строка в экспорте
- Агрегация цен и остатков по всем складам

## Примеры

### Пример 1: Yokohama F7640
```
Склад А: price=9,546₽, stock=20
Склад Б: price=9,800₽, stock=15
Склад В: price=9,650₽, stock=20

Экспорт:
- CP_QUANTITY = 20+15+20 = 55 штук (> 4 ✅)
- MIN(price) = 9,546₽
- CV_PRICE_1 = 9,546₽ × 1.12 = 10,691.52₽
```

### Пример 2: Viatti 3151004
```
Склад А: price=4,359₽, stock=30
Склад Б: price=4,500₽, stock=28

Экспорт:
- CP_QUANTITY = 30+28 = 58 штук (> 4 ✅)
- MIN(price) = 4,359₽
- CV_PRICE_1 = 4,359₽ × 1.12 = 4,882.08₽
```

### Пример 3: Товар с малым остатком
```
Склад А: price=5,000₽, stock=2
Склад Б: price=5,100₽, stock=2

Экспорт:
- SUM(stock) = 2+2 = 4 штуки
- CP_QUANTITY = 0 (так как остаток <= 4) ⚠️
- MIN(price) = 5,000₽
- CV_PRICE_1 = 5,000₽ × 1.12 = 5,600₽
- Товар в каталоге, но недоступен для заказа (количество = 0)
```

## SQL Запрос

```sql
SELECT
    t.cae,
    COALESCE(t.brand, '') as brand,
    COALESCE(t.model, '') as model,
    t.width,
    t.height,
    t.diameter,
    COALESCE(t.season, '') as season,
    CASE
        WHEN t.is_studded = 'шип' THEN 'Шипованные'
        WHEN t.is_studded = 'не шип' THEN 'Нешипованные'
        ELSE ''
    END as studded,
    COALESCE(t.load_index, '') as load_index,
    COALESCE(t.speed_index, '') as speed_index,
    COALESCE(t.runflat, '') as runflat,
    MIN(p.price) as min_price,
    SUM(p.stock) as total_stock,
    MAX(CASE WHEN p.provider IN ('Группа Бринекс', 'Северавто') THEN 1 ELSE 0 END) as has_special_provider
FROM nomenclature_tyres t
INNER JOIN tyres_prices_stock p ON t.cae = p.cae
WHERE t.tiretype = 'Легковая'
GROUP BY t.id, t.cae, t.brand, t.model, t.width, t.height, t.diameter,
         t.season, t.is_studded, t.load_index, t.speed_index, t.runflat
ORDER BY t.id
```

## Важные замечания

### ⚠️ Формат цен в БД
- Цены в таблице `tyres_prices_stock` хранятся в **рублях**, а НЕ в копейках
- Значение `38219` в колонке `price` = 38,219₽ (тридцать восемь тысяч двести девятнадцать рублей)
- Никакой конвертации из копеек не требуется!

### ✅ Правильный расчет
```go
priceRub := float64(minPrice)  // Уже в рублях
priceWithMarkup := priceRub * 1.12
```

### ❌ Неправильный расчет
```go
// НЕ ДЕЛАТЬ ТАК:
priceRub := float64(minPrice) / 100.0  // ❌ Деление на 100 не нужно!
```

### ⚠️ Только легковые шины
- Скрипт экспортирует **только** товары с `tiretype = 'Легковая'`
- Мотошины (tiretype = "Мотошина") не включаются в выгрузку

### ⚠️ Логика остатков
- Экспортируются **ВСЕ** товары, которые есть в `tyres_prices_stock`
- **Товары с остатком <= 4 шт:**
  - Включаются в выгрузку
  - CP_QUANTITY = 0 (недоступны для заказа)
  - Отображаются в каталоге с ценой, но "нет в наличии"
  - Количество: 1,993 товара
- **Товары с остатком >= 5 шт:**
  - CP_QUANTITY = реальный остаток
  - Доступны для заказа
  - Количество: 4,525 товаров
