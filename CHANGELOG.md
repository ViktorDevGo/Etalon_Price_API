# Changelog

Все важные изменения в проекте документируются в этом файле.

## [2026-03-15] - Ведение истории изменений номенклатуры

### Изменено
- ✅ **Логика обновления номенклатуры** - вместо UPDATE теперь INSERT новых версий
  - Убран UNIQUE constraint на поле `cae` в таблицах nomenclature_tyres и nomenclature_rims
  - Теперь одному CAE может соответствовать несколько записей (история изменений)
  - Запись НЕ добавляется только если это **полный дубль** (все поля совпадают)
  - Если хотя бы одно поле изменилось - добавляется новая строка

### Добавлено
- ✅ **Миграция 013** - изменение структуры таблиц номенклатуры
  - Удалены UNIQUE constraints на cae
  - Добавлены индексы для проверки дублей по всем полям
  - Добавлены индексы для быстрого поиска по cae

- ✅ **Планировщик ежедневной синхронизации** - `cmd/nomenclature-scheduler`
  - Автоматический запуск синхронизации номенклатуры
  - Расписание: каждый день в 2:00 AM
  - Использует библиотеку robfig/cron/v3
  - Graceful shutdown при SIGINT/SIGTERM

- ✅ **Документация** - `docs/NOMENCLATURE_HISTORY.md`
  - Объяснение новой логики
  - Примеры запросов для работы с историей
  - Варианты настройки ежедневной синхронизации (cron, systemd, docker)
  - Мониторинг и очистка старых версий

### Изменения в коде
- `internal/repository/nomenclature_repository.go`:
  - UpsertTyres/UpsertRims теперь возвращают (newCount, skippedCount)
  - Вместо `ON CONFLICT DO UPDATE` используется `INSERT ... WHERE NOT EXISTS`
  - Проверка полного совпадения всех полей (включая NULL)

- `internal/service/nomenclature_service.go`:
  - Логирование изменено: `updated` → `skipped_duplicates`
  - Подсчёт пропущенных дублей вместо обновлённых записей

### Миграция
```bash
psql "$DATABASE_DSN" -f migrations/013_modify_nomenclature_for_history.up.sql
```

### Использование планировщика
```bash
# Запуск daemon для ежедневной синхронизации
go run cmd/nomenclature-scheduler/main.go

# Или настроить systemd/cron (см. docs/NOMENCLATURE_HISTORY.md)
```

### Преимущества
- 📊 Полная история изменений товаров
- 🔍 Можно отследить когда и что изменилось
- 💾 Дубликаты не добавляются (экономия места)
- ⚡ Быстрая проверка через индексы
